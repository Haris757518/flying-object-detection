30-PAPER LITERATURE PACKAGE - Flying Object Detection

The Word report contains 30 fully cited research papers with DOI links and a 30-row literature review table.

AVAILABLE ORIGINAL PDFs: 9
NEW ORIGINAL PDFs NOT FETCHED IN THIS ENVIRONMENT: 21
The environment cannot retrieve external PDF bytes (web pages are searchable but remote file download is blocked).
Rather than create fake or reconstructed PDFs, the archive includes each paper's official public PDF or DOI link, plus a Windows downloader.

The archived source files are included as provided in user-supplied research folders.
One original PDF (FBD-SV-2024) is an arXiv preprint; the citation has been updated to its 2025 Scientific Data publication.
The YOLOBirDrone entry is a 2026 preprint, explicitly identified as such.
A retracted 2024 MobVGG paper was excluded.

How to obtain the missing papers on a Windows computer with Internet access:
1. Unzip this package to a local folder.
2. Open PowerShell in that folder.
3. Execute: powershell -ExecutionPolicy Bypass -File .\Download_Missing_Papers.ps1
4. The script downloads only absent files from the URLs in papers_30_manifest.csv.
5. It tests the PDF header and logs successes/failures.
6. Any publisher-blocked files are documented in download_status.csv; use their PDF links in the manifest directly.

Avoid presenting these papers' reported results as results from your own project.
